# Project `es_2.2`: Random Walk Simulation

**Prerequisite**: This project requires the **Armadillo** C++ linear algebra library to be correctly installed and linked on your system.

This repository contains the directory structure and tools required to execute and manage **Random Walk** simulations in both **Discrete** and **Continuous** modes.

## 2. Configuration File Structure

The simulation's behavior and output observables are governed by the `input.dat` and `properties.dat` files.

### `input.dat` Parameters

| Parameter | Description | Notes |
| :--- | :--- | :--- |
| `N_WALKS` | Total number of Random Walks simulated. | |
| `N_BLOCKS` | Total number of blocks used for the blocking method. | |
| `ROW` | Primes file row used to initialize the pseudo-random number generator. | |
| `N_DIM` | Dimensionality of the lattice/space. | |
| `START_POS` | Initial position of the walker(s). | |
| `N_STEP` | Total number of steps performed during a single Random Walk. | |
| `RW_STEP` | Step size for the Random Walk. | |
| `RW_TYPE` | Defines the RW mode: `discrete` (lattice) or `continuous` (uniform direction in space). | The script sets this to **DISCRETE** (uses RNG row 0) or **CONTINUOUS** (uses RNG row 1). |
| `POSITION` | Specifies which Random Walk trajectory will be printed for each block. | |

### `properties.dat` Observables

This file defines which observables will be computed and printed to the output directory.

| Observable | Description | Notes |
| :--- | :--- | :--- |
| `DISTANCE` | Computes the simulation results and the Root Mean Square (RMS) distance from the starting position for each step. | Standard output. |
| `POSITION` | Prints all walker positions for the Random Walk specified by the `POSITION` parameter in `input.dat`. | Remove from both `input.dat` and `properties.dat` if not needed. |
| `LAST` | Prints the final position of all simulated Random Walkers. | Remove from `properties.dat` if not needed. |

## 3. The Execution Script: `run_rw.sh`

The `run_rw.sh` Bash script automates the entire simulation process:

| Phase | Description |
| :--- | :--- |
| **Configuration** | Modifies `RANDOMWALK/INPUT/input.dat`, setting the `RW_TYPE` parameter to `DISCRETE` or `CONTINUOUS`. The modification search is limited up to the `ENDINPUT` line. |
| **Compilation** | If the executable `main.exe` is not present, it compiles the code (calling `make remove_o` and `make remove_exe` beforehand). |
| **Execution**  | Launches the simulation ( `./main.exe` ) from the `SOURCE` directory. |
| **Archiving** | **Copies** the `RANDOMWALK/INPUT` and `RANDOMWALK/OUTPUT` directories to the specific archive folder (e.g., `RW_DISCRETE/`). |
| **Cleanup** | Empties the temporary `RANDOMWALK/OUTPUT` directory by executing `make remove_output`. |

## 4. Automated Usage Guide

To run a simulation, follow these steps from the project's root directory `es_2.2/`.

### 4.1. Preparation

Ensure the script is executable (required only once):

```bash
chmod +x run_rw.sh
```

### 4.2. Execution

Provide the desired mode as an argument.

### For discrete Random Walk simulation:

```bash
./run_rw.sh discrete
```

### For continuous Random Walk simulation:

```bash
./run_rw.sh continuous
```

## 5. Manual Solution / Troubleshooting

If command `run_rw.sh` fails, you can execute the entire process manually by following the exact sequence below.

**NB:** Always start in the project's root directory: `es_2.2/`

### Step 1: Cleanup and Compilation

Start by cleaning up old files and compiling the code from the `SOURCE` directory.

Navigate to the source directory:
```bash
cd RANDOMWALK/SOURCE
```

Complete cleanup (Executable, Objects, Temporary Output):
```bash
make remove_exe
make remove_o
make remove_output
```

Compile the program:
```bash
make
```

### Step 2: Input Configuration

Navigate to the `INPUT` directory and manually modify the `input.dat` configuration file.

Navigate to the input directory:
```bash
cd ../INPUT
```

Open the file and modify it (Choose your preferred editor):
```bash
nano input.dat  
``` 

Modify the RW_TYPE line to set the mode (choose one):
- RW_TYPE DISCRETE
- RW_TYPE CONTINUOUS

Save the file and close the editor.


### Step 3: Execution Run

Return to the source directory and launch the program.

Return to the source directory for execution:
```bash
cd ../SOURCE
```

Run the simulation:
```bash
./main.exe
```

### Step 4: Archiving and Analysis

Once the execution is complete, archive the results in the correct directory and proceed to analysis.

Return to the RANDOMWALK directory:
```bash
cd ..
```

Choose and apply the correct archiving command:
- If the simulation was DISCRETE:
```bash
cp -r OUTPUT ../../RW_DISCRETE/
cp -r INPUT ../../RW_DISCRETE/
```

- If the simulation was CONTINUOUS:
```bash
cp -r OUTPUT ../../RW_CONTINUOUS/
cp -r INPUT ../../RW_CONTINUOUS/
```

Return to the project root for analysis (e.g., Python Notebook):
```bash
cd ..
jupyter-notebook LSN_Notebook_02.ipynb
```
