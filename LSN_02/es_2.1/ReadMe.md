# Project `es_2.1`: Monte Carlo Analysis and Sampling 📊

This exercise focuses on the Monte Carlo calculation of an integral, comparing the effectiveness of **Uniform Sampling** (also known as the **Mean Value Method**), and **Importance Sampling** (using 1st order Taylor polynomial expansion) in terms of **statistical error** and **speed of convergence**.

---

## 1. Project Structure and Data Flow

The `es_2.1` directory is organized to contain the source code, the executable, generated compilation files, and the analysis results.

```
es_2.1/
├── OUTPUT                                          # Repository for raw statistical data (generated post-execution)
│   ├── mean_error_exponential_sampling.data
│   ├── mean_error_importance_sampling.data
│   └── mean_error_uniform_sampling.data
├── ReadMe.md
├── main.cpp                                        # Primary C++ source code.
├── main.exe                                        # Executable binary (build target).
├── main.o                                          # Intermediate object file.
├── makefile                                        # Build automation script.
└── plot                                            # Repository for graphical output (generated by analysis script)
    ├── mean_block_scatter_comparison.png
    └── mean_value_over_blocks.png
```

## 2. Operational Procedure

The following steps should be executed sequentially within the `es_2.1` directory.

### Step 1: Workspace Sanitization (Cleanup)

Prioritize workspace integrity by removing artifacts from previous runs. The `makefile` provides granular cleanup targets:

| Command | Function |
| :--- | :--- |
| `make remove_o` | Removes the intermediate object file (`main.o`). |
| `make remove_exe` | Removes the executable binary (`main.exe`). |
| `make remove_output` | **Removes all raw data files** (`*.data`) from the `OUTPUT/` directory. |

**Recommended Full Sanitization Sequence:**

```bash
make remove_o
make remove_exe
make remove_output
rm -f plot/*
```

### Step 2: Code Compilation

Compile the C++ source code using the provided `makefile` to generate the executable binary.

```bash
make
```

### Step 3: Simulation Execution

Execute the binary to initiate the Monte Carlo calculation. The program will write all block-averaged statistical data to the `OUTPUT/` directory.

```bash
./main.exe
```

### Step 4: Data Post-Processing and Visualization

The final analysis and plot generation are managed by a Jupyter Notebook located in the parent directory (`../`). Launch the specific notebook directly from the current location:

```bash
jupyter-notebook ../LSN_Notebook_02.ipynb
```
