## 0. Introduction

The objective of this project is the **development and performance analysis of a parallel implementation** of the Genetic Algorithm (GA) for solving the Traveling Salesman Problem (TSP), a classic NP-hard problem in combinatorial optimization. Building upon the sequential GA framework developed in the previous exercise, the core of this assignment is the implementation of a **message-passing routine** between distinct processors.

The simulator utilizes a **Distributed Memory Architecture** via the **Message Passing Interface (MPI)** library, specifically implementing the **Island Model paradigm**. This approach divides the total population across multiple independent processes (islands) that evolve semi-independently and periodically exchange elite solutions (migration).

The primary goal of this investigation is twofold:

- To successfully implement the inter-processor communication mechanism for data migration.

- **To compare the convergence results and performance metrics** (speed-up) between the single-processor **Serial** Run and the multi-processor **Parallel** Run (Island Model).

## 2. Configuration File Structure

### `input.dat`: Simulation Parameters

This file contains configuration parameters necessary to set up the simulation.

| Parameter | Recommended Value | Description/Notes |
| :--- | :--- | :--- |
| `RND_ROW` | $0$ | $0$: `Primes` file row read to set the LCG seed. |
| `N_PATH` | $2000$ | Total number of paths (chromosomes) composing the population. |
| `N_ELITE` | $200$ | Number of best paths preserved for the next generation (Elitism) without undergoing crossover or mutation. |
| `N_CITY` | $110$ | Total number of cities composing a single path. |
| `CITY_DISTRIBUTION` | ITALY | Italian province capital cities. |
| `P_SWAP` | *0.10* | Probability of **Swap Mutation**: $L$ contiguous cities are swapped with other non-overlapping $L$ contiguous cities. |
| `P_SHIFT` | *0.10* | Probability of **Shift Mutation**: $L$ contiguous cities are shifted (left or right) by a random step size. |
| `P_CROSSOVER` | *0.80* | Probability of **Crossover**: High-fitness paths are selected to mix genes and create two new individuals. |
| `P_INVERSION` | *0.10* | Probability of **Inversion Mutation**: The order of $L$ contiguous cities is inverted. |
| `N_CHROMO_EXCHANGED` | 100 | Total number of chromosomes exchanged per process during a migration event. |
| `N_MESSAGE` | 10 | Number of migration events per simulation run. |
| `ENDINPUT` | N/A | Marker indicating the end of the input file. |

### `properties.dat`: Measurable Properties

This file lists the properties the simulator measures and outputs.

| Parameter | Description | Implemented |
| :--- | :--- | :--- |
| `BEST_LOSS` | Measure and prints the loss function associated with the best path of the population | ✅ |
| `MEAN_LOSS` | Measure and prints the average loss function associated of the best half path of the population | ✅ |
| `BEST_PATH` | Prints the best path sequence of each generation based on the lowest loss function. | ✅ |
| `ENDPROPERTIES` |  Marker indicating the end of the properties file. | - |

### `italy_prov_mod.dat`

This file contains the distribution of Italian province capital cities, described by city labels (first column), longitude (second column), and latitude (third column). It was produced by executing format_city_file.cpp and reading the input file italy_prov.dat, which contains the Italian province capital cities described by longitude and latitude.

## 3. Compilation and Execution

This section presents the execution routine and file system management for archiving the output data generated during **simulation**. All subsequent commands must be executed from the `LSN_10/GA_SIMULATOR/SOURCE/` directory.


### 3.1 Compilation

- Compile source file `GA.cpp` :

```bash
make
```

- Remove residual files from previous executions:

```bash
make remove
```

- *OPTIONAL:* Remove all files and plot produced by previous executions and rebuild archive structure:

```bash
rm -r ../../MIGRATION
rm -r ../../NO_MIGRATION
mkdir -p ../../MIGRATION/plot
mkdir -p ../../NO_MIGRATION/plot
```

### 3.2 Input Parameters Initialization (Parallel run)

- Open `../INPUT/input.dat` file and copy the following input parameters:

```
RND_ROW 0
N_PATH 2000
N_ELITE 200
N_CITY 110
CITY_DISTRIBUTION ITALY
N_GENERATIONS 1000
P_SWAP 0.10
P_SHIFT 0.10
P_CROSSOVER 0.80
P_INVERSION 0.10
N_CHROMO_EXCHANGED 100
N_MESSAGE 10

ENDINPUT
```

- Open `../INPUT/properties.dat` file and copy the following property parameters:

```
BEST_LOSS
MEAN_LOSS
BEST_PATH

ENDPROPERTIES
```

### 3.3 Execution (Parallel run)

```bash
mpiexec -np 10 ./GA.exe
```


### 3.4 Input and Output Archiviation

- Copy the input and output directories produced by the simulation to `MIGRATION` archive directory:

```bash
cp -r ../INPUT ../OUTPUT ../../MIGRATION/.
```
