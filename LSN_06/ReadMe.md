## 0. Introduction

This project implements and compares two fundamental Markov Chain Monte Carlo (MCMC) algorithms:

- **Metropolis-Hastings M(RT)$^2$ Algorithm;

- Gibbs Sampling Algorithm;

to simulate the thermodynamic behavior of the **one-dimensional (1D) Ising Model**. The 1D Ising model serves as an ideal test due to its analytical solvability, especially the confirmation that it lacks a phase transition at finite temperatures.

The simulation runs are performed across a range of temperatures ($T$) and under two conditions: with an external magnetic field ($h=0.02$) and without it ($h=0.0$). The primary goal is to accurately measure four key thermodynamic observables: **Internal Energy** ($U$), **Magnetization** ($M$), **Magnetic Susceptibility** ($\chi$), and **Specific Heat** ($C_V$). The results from both MCMC algorithms are then compared with the exact theoretical solutions to validate the statistical accuracy of the implemented methods.

## 2. Configuration File Structure

### `input.dat`: Simulation Parameters

This file contains configuration parameters necessary to set up the simulation.

| Parameter | Possible Value | Description/Notes |
| :--- | :--- | :--- |
| `SIMULATION_TYPE` | $2/3$ $J$ $H$ | $2$: Ising 1D MC (MRT$^2$); $3$: Ising 1D MC (Gibbs); $J$: spin coupling interaction; $H$: external magnetic field |
| `RESTART` | $0/1$ | $0$: Start from initial configuration/velocities; $1$: Restart from previous configuration files. |
| `TEMP` | $\in \left[ 0.3; 2.0 \right]$ | Temperature $T$. |
| `NPART` | $50$ | **Do not change** (critical for initialization). |
| `RHO` | $1.0$ | The reduced density $\rho^*$. |
| `R_CUT` | $0.0$ | The cut-off radius (Ising 1D does not use cut-off). |
| `DELTA` | $0.0$ | Metropolis step size. **Note**: This is relevant only for the Metropolis algorithm; Gibbs does not use $\Delta$. |
| `NBLOCKS` | $\in \mathbb{N}$ | Number of blocks for the **blocking method**. |
| `NSTEPS` | $\in \mathbb{N}$ | Number of steps per simulation block. |
| `ENDINPUT` | N/A | Marker indicating the end of the input file. |

### `properties.dat`: Measurable Properties

This file lists the properties the simulator measures and outputs.

| Parameter | Description | Applicable Simulation Type(s) | Implemented |
| :--- | :--- | :--- | :--- |
| `TOTAL_ENERGY` | Average total energy per particle (using blocking) | $2, 3$ | ✅ |
| `TOTAL_ENERGY_STEP` | Istantaneous total energy per particle per step (monitoring thermalization) | $2, 3$ | ✅ |
| `MAGNETIZATION` | Magnetization | $2, 3$ | ✅ |
| `MAGNETIZATION_STEP` | Istantaneous magnetization | $2, 3$ | ✅ |
| `SPECIFIC_HEAT` | Specific Heat | $2, 3$ | ✅ |
| `SUSCEPTIBILITY` | Susceptibility | $2, 3$ | ✅ |
| `ENDPROPERTIES` | N/A | Marker indicating the end of the properties file. |

### `config.ising`

This file contains the **Cartesian coordinates** ($x, y, z$) for each site of the 1D Ising Model lattice.

### `config.spin`

This file contains the last sping microstate produced by the simulation.

## 3. Execution Script: `gibbs_run.sh` and `metropolis_run.sh`

**`gibbs_run.sh`** and **`metropolis_run.sh`** Bash scripts automate the entire exercise workflow, including compilation, sequential execution of all required parts, and output management.

### 3.1. Usage

Before running the simulation, make sure the scripts are executable:
```bash
chmod +x gibbs_run.sh
chmod +x metropolis_run.sh
```

#### Run the simulations
```bash
./gibbs_run.sh && metropolis_run.sh
```

**Script Behavior**: During execution, the script will output status messages indicating which part of the exercise is currently being processed (e.g., Equilibration H on, Simulation H off, etc.).
